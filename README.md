# WEB STUDIO — сайт веб-разработки

Авторский адаптивный сайт на Astro. Проект собирается в статические файлы и не требует Node.js на конечном хостинге.

## Разработка
Требуется Node.js 22 или совместимая LTS-версия.

```bash
npm install
npm run dev
npm run build
npm run preview
```

После сборки готовый сайт находится в `dist/`. Для обычного хостинга загрузите содержимое этой папки в публичный каталог. Для ZIP-архива упаковывайте именно содержимое `dist/`.

## GitHub Pages
Проект настроен на `https://kinodoc.github.io/web-studio/` с базовым путём `/web-studio`. В Settings → Pages выберите GitHub Actions как источник публикации.

Важно: репозиторий private, но опубликованный сайт общедоступен. GitHub Pages для private-репозиториев доступен на GitHub Pro, Team и Enterprise; на Free требуется public-репозиторий. Проверьте доступность Pages перед публикацией.

## Перед реальным запуском
- Заменить временный адрес `hello@example.com` на рабочий.
- Подключить реальную отправку заявок через сервис формы или backend: статический сайт сам не отправляет email.
- При появлении домена обновить canonical, sitemap и конфигурацию Astro.
- Подготовить уникальные тексты услуг под реальные поисковые запросы. Техническая SEO-настройка не гарантирует конкретных позиций.
- Проверить сайт на реальных устройствах и в Lighthouse/PageSpeed.
